# Contributing to AnaOS

Thank you for contributing to The AnaOS Project (hardened Android OS).

## Scope

This project is the **Android AnaOS** tree. The AI Ops product at qizimarket.com/anaos is out of scope.

## License

- Primary: Apache-2.0
- Secondary: GPLv2 where required by upstream

## Developer Certificate of Origin (DCO)

All commits must be signed off:

```bash
git commit -s -m "your message"
```

This certifies the [Developer Certificate of Origin](https://developercertificate.org/).

## Commit style

Use [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`

## Pull requests

1. Fork or branch from `main`
2. Keep PRs focused and small
3. Do not commit private keys, blobs without license clearance, or secrets
4. Reference related plan tasks when useful (e.g. TASK_010)

## Security issues

See [SECURITY.md](SECURITY.md). Do not open public issues for vulnerabilities.
