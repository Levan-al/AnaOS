# AnaOS

Hardened Android OS project. Brand: **Ana**. Package prefix: `org.anaos`.

Not a stock Android clone — three parallel tracks: **AOSP 17 adaptation**,
**security/privacy primacy**, and **PQC + on-device AI alternatives**.
See [`docs/STRATEGY.md`](docs/STRATEGY.md).

> **Scope:** This is the Android OS. The AI Ops product at [qizimarket.com/anaos](https://qizimarket.com/anaos/) is separate — see [`docs/PRODUCT_SCOPE.md`](docs/PRODUCT_SCOPE.md).

## Status

Foundation + strategy v2.1 in progress. Hosting: GitHub under [`Levan-al`](https://github.com/Levan-al) (org `AnaOS` deferred). See [`docs/PLAN.yaml`](docs/PLAN.yaml) and [`docs/BRANDING.md`](docs/BRANDING.md).
