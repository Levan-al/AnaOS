# Product scope

## This repository (Android AnaOS)

Hardened Android OS: AOSP-based, GrapheneOS-inspired security, package prefix `org.anaos`, brand Ana / AnaOS.

Tracked by `docs/PLAN.yaml`.

## Not this repository

**Ana OS — AI Operations Layer** at [https://qizimarket.com/anaos/](https://qizimarket.com/anaos/) is a separate Qizi Venture Studio product (FastAPI / QERP / homeserver). It is out of scope for this Android project.

Do not merge branding, domains, or release pipelines of the two products without an explicit decision.
