# Glossary

| Term | Meaning |
| --- | --- |
| Ana / AnaOS | Product brand / OS name |
| `org.anaos` | Android package prefix |
| Track A | AOSP 17 (major) adaptation |
| Track B | Security/privacy primacy + merge gate |
| Track C | PQC + on-device AI alternatives |
| `BUILD_OK` | Marker that first emulator `m` finished on build host |
| `SYNC_OK` | Marker that `repo sync` finished |
| `OVERLAY_OK` | AnaOS trees copied into AOSP checkout |
| AVB | Android Verified Boot |
| OTA | Over-the-air update package |
| Factory image | Full flashable device image set |
| Air-gap | Offline machine for private keys |
| shiba | Pixel 8 device codename |
| ASP | Android Security Patch / bulletin cycle |
| Sandboxed Play | Optional isolated Google Play layer |
| Hybrid PQ | Classical + post-quantum signatures together |
